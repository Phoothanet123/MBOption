# MB Option — Website + App-style PWA

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิด `index.html` ด้วยเบราว์เซอร์เพื่อทดลองหน้าเว็บ
3. หากต้องการติดตั้งเป็นแอป (PWA) ให้อัปโหลดโฟลเดอร์นี้ขึ้นเว็บโฮสติ้งที่รองรับ HTTPS แล้วเปิดเว็บไซต์ด้วย Chrome/Edge จากนั้นเลือก Install app / Add to Home Screen

## ฟังก์ชันในต้นแบบ
- เข้าสู่ระบบ / สมัครสมาชิก / ลืมรหัสผ่าน
- ตรวจสอบอีเมลให้ลงท้าย `@gmail.com`
- รหัสผ่านขั้นต่ำ 8 ตัวอักษร
- หน้าแรก MB Option พร้อมโลโก้ร้าน
- หมวดหมู่ หมวก เสื้อ กางเกง รองเท้า ถุงเท้า พร้อมหน้าต่าง Popup
- สินค้าตัวอย่างและบันทึกรายการในประวัติการสั่งซื้อ
- รองรับหน้าจอคอมพิวเตอร์ แท็บเล็ต และมือถือ

## ข้อจำกัดสำคัญ
นี่เป็น Front-end prototype สำหรับสาธิตส่งงาน ข้อมูลสมาชิกและประวัติถูกเก็บใน Local Storage ของเบราว์เซอร์เท่านั้น ไม่ใช่ระบบร้านค้าออนไลน์จริงที่ปลอดภัย และการกดสั่งซื้อเป็นเพียงการบันทึกตัวอย่าง ไม่มีการชำระเงินจริงหรือส่งอีเมลรีเซ็ตรหัสผ่าน

หากนำไปใช้งานจริง ต้องพัฒนา Backend/API, ฐานข้อมูล, การแฮชรหัสผ่าน, ระบบยืนยันอีเมล/รีเซ็ตรหัสผ่าน, ระบบสต็อกสินค้า, ตะกร้า, การชำระเงิน และระบบจัดการคำสั่งซื้อเพิ่มเติม
